# Soul Talks with Ruchika

Website for **Soul Talks with Ruchika**, which runs experiential corporate wellness and employee-engagement sessions.

*Pause. Reset. Reconnect.*

## What's inside

- `index.html` — page content and sections
- `styles.css` — styles (cosmic night / gold brand theme)
- `script.js` — starfield, parallax, breathing exercise, program tabs, pick-a-card, enquiry form, ambient sound

It's a static site with no build step or dependencies. To view it, open `index.html` in a browser.

## Features

- Animated night sky with a moon, fireflies and shooting stars
- Interactive 60-second guided breathing reset
- Signature programs shown in tabs, each with its own animated scene
- "Pick a Card" draw from Mystic Friday
- Enquiry form that sends a pre-filled message by WhatsApp or email
- Works on phones, and respects the reduced-motion setting

## Deploy

Any static host works: GitHub Pages, Netlify or Vercel.
